# Personal Portfolio Web Page

A responsive personal portfolio website built with **HTML5 and CSS3** for an HTML and CSS assignment. This project showcases my introduction, skills, education, projects, and contact form while demonstrating essential web development concepts.

## 📌 Project Overview

This project creates a personal portfolio webpage using semantic HTML elements and CSS styling techniques. The webpage is designed to be simple, user-friendly, and responsive across different screen sizes.

## ✨ Features

- **About Me:** Personal introduction and professional background.
- **Skills:** Overview of technical skills and expertise.
- **Education:** Academic qualifications displayed in a table.
- **Projects:** Showcase of personal and practice projects.
- **Contact Form:** Form with name, email, subject, message, and submit button.
- **Media Integration:** Includes an image and a video or audio element.
- **Responsive Design:** Layout adapts to different screen sizes.
- **Interactive Styling:** Hover and focus effects for improved user experience.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Box Model
- CSS Selectors and Specificity
- CSS Pseudo-classes
- CSS Transforms
- Responsive Web Design

## 🎯 HTML Concepts Applied

- Semantic elements such as `header`, `nav`, `main`, `section`, and `footer`.
- Structured content using headings, paragraphs, lists, and links.
- Academic qualifications displayed using an HTML table.
- Contact form with input fields and a submit button.
- Image and video/audio integration.
- Text formatting using tags such as `strong`, `em`, and `mark`.

## 🎨 CSS Concepts Applied

- **Box Model:** Margin, padding, and border.
- **Flexbox:** Flexible and organised page layouts.
- **CSS Units:** `px`, `em`, `rem`, and `vw`.
- **Pseudo-classes:** `: hover`, `: focus`, and other interactive states.
- **Typography:** Font family, size, weight, and line height.
- **Selectors and Specificity:** Element, class, and ID selectors.
- **Transform Effects:** Scale, rotate, or translate effects on hover.
- **Responsive Styling:** Media queries for different screen sizes.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the correct locations.
4. Open `index.html` in your web browser.
5. Alternatively, use the **Live Server** extension in Visual Studio Code to preview the webpage.
